# OpenStudio

스텝을 연결해 영상을 완성하는 웹 워크플로우 도구. 현재는 **계정 연결과 실제 모델 호출 검증** 단계입니다.

## 실행

Node.js 22.12 이상.

```sh
npm install
npm run dev
```

터미널에 실제 주소가 출력됩니다. 매번 임의의 **빈 포트에 실제 리스너를 바인딩**합니다.

- 프런트: `http://localhost:3xxx` 또는 `http://127.0.0.1:3xxx` (3001–3999)
- 백엔드: `http://127.0.0.1:4xxx` (4001–4999)
- OpenAI callback: `http://127.0.0.1:4xxx/auth/callback`
- OpenRouter callback: `http://127.0.0.1:4xxx/auth/openrouter/callback`
- 브라우저의 `/api/*` 요청은 프런트 서버가 백엔드로 프록시합니다.
- IPv4 `127.0.0.1`과 IPv6 `::1`에만 바인딩하며 3000번을 사용하지 않습니다. localhost의 API 요청과 개발 WebSocket도 지원합니다.
- OAuth 콜백은 시작한 호스트(localhost 또는 127.0.0.1)를 유지합니다. 두 호스트의 브라우저 쿠키는 별개이므로 기존 127.0.0.1 연결은 그 주소에서 계속 사용할 수 있습니다. localhost를 처음 열면 별도 워크스페이스입니다.

로컬 개발용 암호화 키는 첫 실행 시 `.data/master.key`에 자동 생성됩니다. 별도 환경 설정 없이 화면·OpenAI OAuth를 시작할 수 있습니다. 키와 `.data/*.enc`는 Git에서 제외됩니다. 기존 키를 삭제하면 저장한 인증 정보를 복호화할 수 없습니다.

## ChatGPT 구독 OAuth

1. **연결 → OpenAI → 계정 연결 → OAuth**
2. **Continue with ChatGPT** 클릭
3. OpenAI 로그인 창에서 OpenStudio 등록과 구독 사용 권한 승인
4. **모델 실행 → 텍스트 → 연결 계정 → 모델** 선택
5. 프롬프트 입력, 사용량 동의 후 **실행**

공식 [ChatGPT plan usage in open-source apps](https://developers.openai.com/siwc/token-sharing-open-source/sign-in) 흐름을 사용합니다.

- 최초 등록은 공식 `dynamic_agent_client` 진입점을 사용하며 OpenStudio 자체 client ID가 발급됩니다.
- 다른 앱의 client ID나 기존 OpenCode/Codex 인증 파일을 사용하지 않습니다.
- `state`, nonce, PKCE를 매번 생성하고 인증을 시작한 브라우저 세션에 연결합니다.
- 백엔드 4xxx의 loopback callback에서 코드를 교환합니다.
- OpenAI JWKS로 ID 토큰의 서명·issuer·audience·만료·nonce를 검증합니다.
- 로그인 성공과 `chatgpt.tokens.use.direct` 구독 권한을 구분합니다.
- 발급된 client ID와 계정 identity를 유지해 다시 로그인할 때 재사용합니다.
- 토큰은 서버에 암호화 저장하고 만료 전에 회전 갱신합니다.
- 모델 목록은 연결 계정의 `GET https://api.openai.com/v1/models`로 조회합니다.
- 호출은 공개 `POST /v1/responses`를 사용합니다. 이 공식 경로에서는 ChatGPT backend-api를 사용하지 않습니다.
- 구독 호출은 `store:false`, `stream:true`, 배열형 input을 사용하며 `response.completed`를 받아야 성공입니다.
- `max_output_tokens` 등 구독 경로에서 금지된 API 옵션은 보내지 않습니다.
- 연결 해제 시 갱신 세션의 원격 폐기를 시도하고 로컬 토큰을 삭제합니다. 계정/client 등록 매핑은 재로그인용으로 유지합니다.

브라우저에서 실제 OpenAI 로그인 페이지 진입을 확인했고, 이후 사용자가 재시도로 정상 호출을 보고했습니다. 응답 원문과 계정 정보는 수집하지 않았습니다. OAuth 승인은 사용자가 직접 진행합니다.

공식 직접 등록은 local/self-hosted OSS용 preview 흐름입니다. 원격 공유 웹서비스의 제품 로그인·서버 운영과 동일하지 않습니다. 현재 앱은 loopback 개발 환경에 맞춰져 있습니다.

## OpenRouter OAuth

연결 → OpenRouter → 계정 연결 → OAuth 로그인 → 승인 후 작업 유형·연결 계정·모델 선택.

- 공식 PKCE/S256와 일회성 state를 사용합니다. 별도 client ID 설정은 필요하지 않습니다.
- 로그인으로 사용자 소유 API 키를 발급받고 `/api/v1/key`로 확인한 뒤 암호화 저장합니다. ChatGPT 구독과 달리 **OpenRouter 크레딧 과금**입니다.
- 공개 텍스트·이미지·영상 모델 목록을 보완적으로 조회합니다. 키 검증과 모델별 실제 실행 권한은 별개입니다.
- 원격 키 권한은 OpenRouter 키 설정에서 관리합니다. 앱의 연결 해제는 로컬 인증 정보를 삭제합니다.

## API 키 제공자

OpenAI, BytePlus ModelArk, Anthropic/Claude, Google Gemini, OpenRouter, fal, xAI, DeepSeek, Groq, Mistral, ElevenLabs를 연결할 수 있습니다.

- **Anthropic**: 모델 페이지 조회와 Messages API. Claude.ai 구독 OAuth를 직접 제공하거나 Claude 구독 토큰을 가져오지 않습니다.
- **Google**: 모델 조회와 `generateContent`. API 키는 URL이 아닌 `x-goog-api-key` 헤더에 보냅니다. 현재 어댑터는 텍스트입니다.
- **OpenRouter**: 키 검증, 공개 텍스트·이미지·영상 모델 목록, 텍스트 호출과 미디어 API.
- **fal.ai**: API 키로 연결한 뒤 작업 화면에서 모델 목록을 선택하거나 전체 모델을 검색·페이지 조회합니다. 호출 경로와 입력 명세는 앱이 처리합니다.
- **xAI/DeepSeek/Groq/Mistral**: 모델 조회와 Chat Completions 텍스트 어댑터.
- API 키를 회전하려면 기존 계정에서 **API 키 갱신**을 사용합니다. 새 키를 검증한 뒤 동일 연결 ID의 키를 교체하므로 기존 외부 작업을 이어서 추적할 수 있습니다.

- **OpenAI → API 키**: 키 입력 → 서버가 `/v1/models`로 검증 → 계정 저장. ChatGPT 구독과 별도 과금입니다.
- **GitHub Copilot**: `.env.local`에 `GITHUB_COPILOT_CLIENT_ID`를 설정하고 서버를 재시작합니다. 사용할 권한이 있고 device flow·Copilot API 접근이 허용된 OAuth 앱이 필요합니다. 일반 GitHub 로그인 성공은 Copilot 모델 호출 성공과 다릅니다.
- 기존 OpenAI·Copilot 어댑터는 텍스트입니다. 미디어 생성은 **BytePlus·OpenRouter·fal**에서 지원합니다.

## BytePlus ModelArk 직접 연결

1. **연결 → BytePlus ModelArk → 계정 연결**에서 ModelArk API 키를 입력합니다.
2. 현재 지원 리전은 공식 문서에서 확인한 **Singapore / ap-southeast-1**입니다. 데이터 플레인은 `https://ark.ap-southeast.bytepluses.com/api/v3`입니다.
3. 키로 `GET /models`를 호출해 계정에 보이는 기반 모델을 조회하고 출력 modality로 이미지·영상·텍스트를 구분합니다.
4. 작업 화면에서 **유형 → BytePlus 연결 계정 → 조회한 모델**을 선택해 실행합니다.

모델 목록은 계정 API 응답을 사용하며 사용자가 별도로 모델이나 호출 주소를 등록하지 않습니다. API에서 모델이 조회되지 않으면 조회 상태와 오류를 확인합니다. 기반 모델·권한을 확인하지 못한 항목은 실행 가능으로 가장하지 않습니다.

### 이미지와 영상

- 이미지 생성·편집: `POST /images/generations`. 참조 이미지는 `image` 문자열 또는 배열로 전송합니다. 현재 단일 이미지 생성 요청(`sequential_image_generation: disabled`)과 최대 3장 참조를 지원합니다.
- 크기 `size`, `output_format`, 시드·워터마크·배경 등의 공통 필드를 지원합니다. 모델별 지원값은 별도로 확인해야 하며 앱 입력 범위를 모델의 실제 한도로 표시하지 않습니다.
- 영상 제출: `POST /contents/generations/tasks`. `content`에 프롬프트와 최대 2장의 시작·끝 프레임을 담습니다. `ratio`, `resolution`, `duration` 등은 ModelArk 필드명으로 전송합니다.
- 영상 조회: `GET /contents/generations/tasks/{id}`. queued/running을 추적하고 succeeded의 `content.video_url`을 확보합니다. 작업 ID 불일치·실패·취소·만료·완료 URL 누락은 성공으로 처리하지 않습니다.
- 이미지 URL 또는 base64 결과와 영상 URL은 서버 파일 저장소에 수신합니다. CDN에 API 키를 보내지 않고, 서명된 URL을 브라우저에 노출하지 않습니다.
- 키 검증·목록 조회는 생성 성공과 별개입니다. 현재 실제 BytePlus 키나 크레딧으로 생성한 결과는 아직 검증하지 않았습니다.

```sh
# 선택 설정을 사용할 경우
cp .env.example .env.local
```

## 현재 화면

- **연결** 화면: 프로바이더별 OAuth/API 키 연결, 계정별 모델 새로고침·재인증·키 갱신·연결 해제.
- 카드와 왼쪽 계정 목록에 연결됨·연결 확인 중·재인증 필요·권한 확인 필요·재확인 실패·연결 안 됨을 표시합니다. 연결된 프로바이더를 먼저 배치하고 인증 확인·모델 개수·확인 시각·실제 실행 여부를 펼쳐 보여줍니다.
- 연결 완료 메시지의 **모델 선택하기**로 작업을 시작합니다. **연결 다시 확인**은 모델 조회로 인증을 재확인하며 유료 생성을 실행하지 않습니다. 재확인 오류는 해당 계정에 저장되고 성공 시 해제됩니다.
- 왼쪽 **연결 계정**에서 기존 계정을 선택해 작업 화면으로 이동합니다.
- **모델 실행**: 텍스트 / 음성 / 이미지 / 영상 → 연결된 프로바이더·계정 → 해당 계정의 모델. 모델 등록 절차 없이 바로 선택합니다.
- fal.ai의 전체 모델 검색·페이지 조회는 작업 화면에서 사용합니다. 검색 결과를 선택하면 호출 주소를 입력하지 않고 실행할 수 있습니다.
- models.dev는 조회한 모델의 사양·가격을 보완하는 참고 자료입니다. 실행할 모델 목록의 기준은 제공자 API 응답입니다.
- 모델 정보: 컨텍스트·최대 입출력·입출력 유형·추론·도구·구조화 출력·API 기본/캐시/컨텍스트 구간별 단가
- 계정 API의 명시적인 제한을 우선하고 models.dev 참고 사양은 출처를 표시해 보완합니다. 연결 관리나 작업 화면의 **모델 새로고침**에서 갱신할 수 있습니다.
- 사양·가격·출처는 작업 화면의 접힌 상세 영역에 표시합니다. 구독 사용량과 API 참고 가격은 구분합니다.
- 기존 연결·작업을 보존합니다. 모델 목록을 갱신해 선택 모델이 사라지면 다른 모델로 자동 교체하지 않고 다시 선택하도록 표시합니다.
- 텍스트·음성·이미지·영상 결과는 **작업 기록**에서 확인합니다. 텍스트 기록은 이번 변경 이후 성공한 호출부터 서버에 저장됩니다.
- 워크플로우·에셋 편집기는 후속 단계입니다.

## 음성 생성 (TTS)

1. **연결 → ElevenLabs**에서 계정을 연결합니다.
2. **모델 실행 → 음성 → 연결 계정**에서 `can_do_text_to_speech`가 참인 모델을 선택합니다.
3. 계정 보이스를 검색·선택하고 읽을 원고를 입력합니다. 보이스 검색은 페이지 추가 조회를 지원합니다.
4. 크레딧 사용 동의 후 생성합니다. MP3를 서버에 저장하고 재생·다운로드·작업 기록을 제공합니다.

TTS는 현재 ElevenLabs API 키를 사용합니다. 보이스 접근 권한과 실제 사용량은 제공자에서 확인합니다. 입력은 제공자 문자 한도와 앱의 4,000자 한도 중 작은 값이며, 문자 한도를 토큰 한도로 표시하지 않습니다. STT는 후속 작업입니다. 실제 키 조회·유료 음성 생성은 아직 미검증이며 자동화 테스트는 모의 응답을 사용합니다.

## 이미지·영상 생성

1. **연결** 화면에서 BytePlus·OpenRouter·fal 계정을 연결합니다.
2. **모델 실행**에서 **이미지 / 영상 → 연결 계정 → 모델**을 선택합니다.
3. 선택한 모델의 프롬프트·화면비·해상도·길이 등 표시되는 옵션을 설정합니다.
4. 필요한 참조 이미지를 업로드하거나 저장된 생성 이미지에서 선택합니다.
5. 사용량 동의를 선택하고 **생성**합니다. 결과와 이전 작업은 **작업 기록**에서도 볼 수 있습니다.

- fal의 추가 필수 옵션은 **추가 모델 옵션(JSON)**에서 입력합니다. 최종 입력은 서버에서 제공자의 OpenAPI 스키마로 검증합니다.
- OpenRouter 이미지는 선택한 endpoint에 고정해 옵션이 다른 fallback으로 넘어가지 않게 합니다.
- 영상·fal Queue 작업은 제출 후 외부 작업 ID로 조회하며 페이지를 다시 열어도 추적합니다. 조회 오류로 생성을 다시 제출하지 않습니다.
- OpenRouter의 동기 이미지 요청 중 서버가 재시작되거나 제출 결과가 불명확하면 **제출 결과 미확인**으로 남기고 자동 재생성하지 않습니다.
- 생성 요청에는 클라이언트 요청 ID를 사용해 동일 요청의 중복 제출을 막습니다. 의도적으로 새 생성 버튼을 누르는 것은 별도 작업입니다.
- 결과는 `.data/assets/<session>/`에 저장합니다. 비밀 URL을 브라우저로 넘기지 않고 인증된 `/api/assets`에서 재생·다운로드합니다. 영상은 Range 요청을 지원합니다.
- 참조 이미지는 PNG/JPEG/WebP/GIF, 장당 20MB·최대 3장입니다. OpenRouter 영상은 현재 시작 프레임 한 장을 지원합니다. 생성 결과는 이미지 20MB, 영상 200MB, 최대 10개입니다.
- SVG/AVIF 등 현재 저장 어댑터가 지원하지 않는 결과 형식은 성공으로 처리하지 않습니다.
- 단일 프로세스 로컬 검증용이며 외부 작업 조회는 화면이 열린 동안 진행됩니다. 브라우저를 닫아도 제공자의 생성 작업은 계속되며 재접속하면 조회를 재개합니다.

### Seedance 요구 버전

요구사항은 **Seedance 5.0 이상**입니다. 현재 확인한 공식 문서와 API에서 해당 버전을 찾지 못했으므로 지원한다고 표시하지 않습니다. 공개 목록의 하위 Seedance 버전은 모델 선택창에서 실행 불가로 표시하고 서버에서도 차단합니다. Seedream은 별도의 이미지 모델로 취급합니다.

## fal.ai 모델 연결·관리

1. **연결 → fal.ai → 계정 연결**에서 Model APIs API 키를 입력합니다.
2. 작업 화면에서 **이미지/영상 → fal.ai 연결 계정 → 모델**을 선택합니다.
3. 최신 목록 밖의 모델은 **fal.ai 전체 모델 검색**에서 키워드·입력 방식으로 검색하고 **더 보기**로 이어서 조회합니다.
4. 검색 결과의 **선택**을 누르면 바로 작업 입력으로 이어집니다. 별도 모델 등록이나 호출 주소 입력이 없습니다.

- 공개 검색은 인증·권한·크레딧 검증이 아닙니다. 키를 포함한 모델 조회 요청은 fal이 인증을 검증하며, 모델별 실제 실행 가능 여부는 생성 요청에서 별도로 확인합니다.
- 스키마의 로컬 `$ref`·`allOf`와 참조 이미지 배열 한도를 반영합니다. 최종 입력은 원본 스키마로 서버에서 검증합니다.
- `prompt` 필드가 없는 이미지 처리 endpoint는 프롬프트 없이 참조·옵션만 전송합니다. 다른 제공자나 prompt 필드가 있는 모델에는 빈 프롬프트를 허용하지 않습니다.
- Queue 제출 이후에는 fal이 반환한 상태/결과 URL과 외부 작업 ID를 사용합니다. 조회 오류로 다시 생성하지 않으며 성공 결과는 서버의 세션별 파일 저장소에 저장합니다.
- 실제 공개 카탈로그 검색·페이지 조회와 입력 폼은 확인했습니다. 유료 생성은 자동으로 검증하지 않습니다.

## 데이터와 운영

- 인증 정보는 `.data/*.enc`에 AES-256-GCM으로 암호화합니다.
- 생성 파일은 owner-only 권한으로 세션별 파일 저장소에 저장합니다. 인증 정보와 작업 메타데이터는 암호화되며 미디어 파일 자체는 암호화되지 않습니다.
- HttpOnly/SameSite=Lax 쿠키로 브라우저 세션을 격리합니다. Lax는 OpenAI의 top-level callback을 받기 위해 사용합니다.
- 브라우저 저장소·응답·로그에 토큰을 넣지 않습니다.
- 세션 쿠키는 30일간 유효합니다. 쿠키를 삭제하면 해당 브라우저의 저장 계정에 접근할 수 없습니다.
- 파일 저장과 잠금은 단일 프로세스 검증용입니다. 공유 서비스 배포에는 사용자 로그인·DB·분산 잠금·만료 데이터 정리가 필요합니다.
- `npm run build && npm start`로 로컬 프로덕션 빌드를 실행합니다. 이 경우 `OPENSTUDIO_ENCRYPTION_KEY`에 32바이트 hex 키가 필요합니다. 실행 포트 범위와 API 프록시는 개발 환경과 같습니다.
