60대 아버지의 성경 쇼츠 영상 만드는 워크플로우

영상: https://www.youtube.com/@%EB%AF%BF%EC%9D%8C%EC%98%81%EC%83%81/shorts

원하는 영상 타입: 성경의 한 "챕터" 를 목소리로 해설해주는 나래이션으로 바꿔서 해설해주는 목소리와함께 해당 구절을 사진/영상으로 재구성하여 배경화면으로 보여주는 1~2분짜리 쇼츠 영상.

현재는 OpenCode 에 skill 로 만들어져있어서

OpenCode 프로젝트 폴더에서 채팅에 "마태복음 10장 쇼츠 영상 만들어줘" 하면 아래의 모든 워크플로우가 자동으로 실행됌.

1. 온라인에서 마태복음 10장 성경 구절 전체를 읽는다.
2. 해당 구절을 20문장짜리 해설로 바꾼다. (한문장은 6~8초내에 읽을수있는 정도)
3. 한 문장당 하나씩 Gemini API 로 이미지로 변환 -> 문장은 TTS 로 목소리로 변환
4. 이미지 20장 + 문장 나래이션 20개 오디오 + 찬송가 배경음악 이 모두 준비되면 ffmpeg 로 모두 이어붙이고 나래이션 자막을 달아서 1~2분짜리 mp4 쇼츠 영상을 생성한다. (이때 영상 포맷은 항상 같기때문에 Agent 가 코드를 짜는것이 아닌, 미리 짜둔 코드를 에셋들과 함께 실행함)
5. Google Cloud 의 youtube API 로 해당 영상을 private 으로 업로드한다.
6. 검수 수에 public 으로 변경한다.
